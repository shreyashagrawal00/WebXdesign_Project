## 2025-05-14 - Smooth Data Synchronization in SPAs
**Learning:** Replacing full-page reloads (`window.location.reload()`) with targeted data refreshes through context providers significantly improves the perceived smoothness of the application. This approach maintains the user's scroll position and UI state while providing immediate feedback via localized loading indicators. Adding `role="status"` and `aria-live="polite"` ensures that these background updates are communicated to screen reader users without interrupting their workflow.
**Action:** Always prefer localized state updates over page reloads. When an action triggers a data refresh, use a `try...finally` block to manage a local `isLoading` state and ensure the UI remains responsive and accessible throughout the async lifecycle.
